#A1 Disseny i creacio del formulari web d'incidencies

**Incidencies associada:** #2 Disseny i creacio del formulari web d'incidencies (Rol A)

## Nom de la tasca (Que?)

Desenvolupar la interficie web perque els usuaris puguen registrar una nova incidencia de manera sencilla

## Moduls i RA (Per que?)

Modul: MP05 (serveis en xarxa)
RA associats: MP05-RA2: Instalar i configurar serveis web.

## Modalitat (Com?)

Individual, liderada per el rol A

## Producte entregable (Suport)

Fitxer de codi font a la carpeta del projecte

## Instruccions pas a pas 

1. Disenyar la estructura HTML del formulari
2. Afegir els camps de descripcio i equip
3. Programar la connexio per guardar les dades.
4. Documentar els pasos i les incidencies al repositori.

## Recursos necesaris

- Ordinador, editor de codi (Visual studio) i entorn web

## Durada i setmana (Quan?)

10 hores. Setmana 2 del projecte

## Lloc de realitzacio (Aon?)

Aula d'informatica

## Responsable (Qui?)

Rol A (executa)
Rol A (revisa)

- [ ] Disseny correcte dels camps
- [ ] Funcionament del formulari 
- [ ] VAlidacio de dades
